# 장소
**v4.2 공통:** MAIN_CURSOR=다음 미완 메인 ID, 선택형 S/T/R 종료·거절·패배 후 저장한 커서로 돌아온다. DONE 메인은 재대화만, 최초 보상 1회. NPC 관전 MATCH와 플레이어 직접 MATCH는 별도 ID, WIN/LOSS/WITHDRAW/VIEW/NOT_ENTERED 구분. 칩 0에서도 무료 이동·훈련·안전 수입 제공.
거목 기슭 도토리시장 F0→뿌리 통로·보관고 F1→나선 계단/작업 승강 수레 F2→가지의 상부 마을 F3→외부 시범전 전망대 F4→거목 내부 대형 카지노 타워 F5→항구행 정기 공공 교통 F6. 위·아래 마을은 동일한 평면 맵으로 뭉개지지 않고 레벨/전망대 표지로 구분. 미성년으로 보이는 주민의 현금/게임 내 금전 베팅 연출 배제.
## 03-M01 높이를 처음 보다
**조건:** 02-M06 이후 F0, 주민 견과상 미루(가칭)·다온. **행동/연출:** 거목 뿌리 사이로 공중 수레가 올라가는 장면과 높은 타워 실루엣. 미루 "뿌리시장은 아랫마을. 시범전은 줄기 지나 저 위예요." 한강에서 '경기'를 택했으면 주인공 "도윤 시범전은 어디서 하죠?"→"상부 전망대"; '숲 풍경' 택했으면 "올라가는 길은 몇 개예요?"→"수레와 계단 둘 다요." 기본은 "위로 올라가 볼래요."
**완료/다음:** F2 표지/안전 지도 갱신→03-M02. 아래 마을 무료 카드 규칙 학습/견과 수집은 선택. 추락 재난 연출과 타워 격파 선행 금지.
### 03-M01 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 02-M06 이후 F0 도착 MAIN_CURSOR=03-M01. 강변에서 숲 경관을 택했으면 미루 “전망은 높은 가지에서 더 좋아요”, 프로를 택했으면 “도윤 경기는 상부 무대예요”, 선택 미기록이면 “수레와 계단 중 골라 보세요.” “먼저 시장 볼게”→미루 “보관고도 자유로워요”; “수레 탈래”→“정류장은 F2”, “직접 올라갈래”→“안전 계단은 저쪽.” 길 표지 조사하면 DONE_03_M01→03-M02, 재대화 미완 “오를 길 먼저 정하세요”, 완료 “위쪽 마을을 지나 시범전이 열려요.” 선택형 S/T/R 조기 방문은 MAIN_CURSOR 저장·복귀, 공식 참가 기록 생성 안 함.
## 03-M02 나무의 두 길
**조건/장소:** F1\~F3, 미루·상부 주민. **플레이:** 계단을 고르면 뿌리 동굴·나뭇잎 관측지를 조사해 높은 시장 생활 발견, 수레를 고르면 빠르게 F3으로 이동하되 나중에 계단 자유 탐험 가능. 바람길에서 잘못 움직이면 가장 가까운 안전 쉼터로 돌아감.
미루 "빨리 올라갈래요, 구경하면서 올라갈래요?" 주인공 "수레는 누가 고쳤어요?" → "타워 손님 많아져서 후원받아 수리했어요. 주민 다리는 우리가 따로 고치는 중이고요."
**완료:** F3 상부 마을 도착→03-M03. 선택형 주민 다리를 고치지 않아도 정식 우회 계단으로 도착. 탐험 발견 보상은 장소 기록·작은 안전한 게임 재화.
### 03-M02 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 계단 선택→미루 “중간 전망대에서 쉴 수 있어요”→F1/F2 경유해 F3, 승강 수레 선택→“그럼 출발할게요”→F3, 산책 중단→“수레도 남아 있어요.” 안전선 오답/바람길 실패→상부 주민 “이쪽 쉼터로 돌아오세요. 안전 계단이 열려 있어요”→F2 재선택, 돈 0에도 수레/계단의 필수 이동 무료. 다리 보수는 03-S01 선택형이고 두 길 중 하나는 항상 개방. F3 도착 시 DONE_03_M02→03-M03. 재대화 “도윤 무대는 전망대에 있어요.”
## 03-M03 도윤의 짧은 공개 실전
**조건/장소:** F4 공개 시범전 장소, 진행자·도윤·상대 NPC. 관전 가능 시간은 플레이어가 도착해야 진행; 지나쳤다면 결과판/짧은 리플레이에서 필수 인물 소개를 확인.
진행자 "오늘의 순회 프로 도윤 선수입니다." 관객 "지난번 판에선 콜을 했더라." 도윤 "지난번 사람이 오늘 같은 수를 쓴다는 법 있나요?"
**실제 액션/정보:** NPC끼리의 짧은 별도 관전 경기에서 공개된 스택·액션과 마지막 한 번의 중요한 콜/폴드를 표시한다. 카드 리플레이는 후속 엔진에서 유효한 덱/액션으로 구성해야 하며 대본에서 특정 우월 핸드 강제 배분 금지. **선택형 관찰 버튼** "상대가 블러프한 것 같아"/"강한 패일 수도"/"그냥 경기 더 보자"는 대사·도윤의 짧은 반응만 바꾸고 공식 성적·다음 지역 해금 영향 없음.
도윤 "구경만 할래요? 옆 테이블은 직접 참가할 수 있어요."
**완료:** DOYUN_FIRST_SEEN=TRUE, MATCH_NPC03_RESULT는 플레이어 조작 전적과 별개→03-M04.
### 03-M03 선택 후 대사·재대화·복귀 (v4.2)
**보완:** F4 진행자 “전체 경기/핵심 액션 요약/결과판 중 무엇을 볼래요?” 전체·요약→NPC 별도 경기만 재생, 결과판→“순회 프로 도윤의 오늘 공개전 기록입니다.” 주인공 예측 “콜/폴드/그냥 보기”→진행자 “확인해 보죠/직접 보면 알 수 있겠죠”로 반응만, 승패·지역 개방 영향 없음. 무대를 먼저 지나쳤다면 F3 전광판에서 도윤 이름과 공개 액션 요약 확인 후 FIRST_SEEN. 재대화 미완 “결과판만 보셔도 소개를 확인할 수 있어요”, 완료 “프로와 직접 겨루려면 F3 연습 테이블이에요.” DONE_03_M03→03-M04, 관전 안 한 사용자에게 “내 판을 눈으로 봤잖아” 금지.
## 03-M04 도윤과 솔개 — 다른 방식의 고수
**조건/장소:** F3 공동 식당·F5 카지노 로비, 도윤·대표 솔개. 도윤 직접전 선택 "지금 붙을게"/"타워 구경부터"/"경기는 나중에". 직접 참가 시 별도 공정 매치; 주인공 승 "이번 판은 네가 가져갔어", 패 "다음에는 다르게 치겠지", 미참여 "그때는 구경만 했지?"가 항구 재회 첫 한 줄의 조건으로 기록.
솔개는 식당에서 주민과 작은 판을 치며 긴 경기에서 서두르지 않는 태도를 보인다. 솔개 "수레는 후원으로 고쳤지만 다리는 마을 사람들이 고쳐야죠. 내가 탑에 있어도 위아래 왔다 갔다 해야 해서요." 주인공 "타워 정상에서도 경기해요?"→"아래층 거쳐서 올라오면."
**완료:** SOLGAE_INTRO=TRUE, F5 로비 무료 공개, 03-M05 활성. 도윤 직접전 승리를 대표 타워 승리로 기록하지 않음.
### 03-M04 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 도윤 “지금 붙을래요, 아니면 솔개 타워부터 볼래요?” 직접전→별도 매치 ID, 전체 WIN “이번 판은 네가 가져갔네”, LOSS “오늘은 내가 가져갈게”, WITHDRAW “중간에 멈췄으니 다음에 새로 하죠”; 관전/미참여 “오늘은 안 붙었죠”→DOYUN_DIRECT_03=NOT_ENTERED. 솔개 식당 시연/타워 로비 먼저→“손님 오면 타워 올라가야 해서요. 공개판은 식당에도 있어요.” 솔개 안내와 도윤 선택 중 어느 순서라도 두 사람 이름/생활 소개 확인 후 DONE_03_M04→03-M05. 재대화 “항구 초청전에서 두 선수가 만날지도 모른대요.” 도윤 직접전 승리로 항구 NPC 경기 결과 변경 금지.
## 03-M05 이안과 도윤이 항구에서 만난다
**조건/장소:** F4의 포스터 또는 F6 교통 안내, 다온. 문구 "갈매기항 초청전 — 이안·도윤 같은 행사 출연". 다온 "두 선수 같은 테이블이면 재미있겠는데요. 물때 맞는 배는 오후에도 있어요."
주인공 선택 "그 둘 경기 보러 갈래"/"해안도 구경하고 싶어"/"숲에서 더 놀래". 앞 둘은 F6 정기 이동으로 04 지역 열림, 세 번째는 남았다가 언제든 이동. **완료:** 04_UNLOCKED는 솔개 타워/주민 다리 수리/도윤 개인 매치 미완에도 true. 아직 이안 vs 도윤 **누가 이길지 말하면 안 됨**.
### 03-M05 선택 후 대사·재대화·복귀 (v4.2)
**보완:** F4 공개 대진표가 항구의 **예정 출연**만 알린다. 주인공 “이안이 도윤과 붙을까?”→미루 “같은 행사라고만 나왔어요. 가서 확인해요”, “바닷가도 가고 싶어”→“항구행 정기 교통은 F6”, “조금 더 올라가 볼래”→“다음 차도 있어요.” 앞 두 가지 택하면 DONE_03_M05/REGION04_UNLOCKED/MAIN_CURSOR=04-M01, 남기는 03-M05 미완으로 자유 탐험. 다리 공사 미참여·도윤 직접전 LOSS/WITHDRAW·솔개 정상 미격파·칩 0에도 기본 교통 이용. 재대화 출발 전 “갈매기항행으로 갈래요?”, 이후 귀환 “항구 소식은 바깥 공고판에도 남아 있어요.”

## 03-S02 견과 보관고
**입구:** F1 식당 주인 "도토리 자루를 위아래로 구분해 주세요." 플레이어가 자루 그림과 납품 표식에 맞춰 2개 선반에 놓으면 안전한 게임 재화. 틀리면 주민 "이쪽은 윗마을 거"라고 다시 안내하고 무료 재시도. 선택 중단해도 도윤 시범전과 항구 출발 진행. **일상 수입:** 정기 견과 분류·안전한 산책로 수집, 어린 주민은 무베팅 교육판만.
### 03-S02 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 식당 주인 “윗마을 자루와 아랫마을 자루를 그림대로 나눠 주세요.” 수락→선반 조사, 오답 “도토리 무늬가 위쪽이에요. 다시 놓아 봐요”; 정답 “창고가 비었네요. 이건 일한 몫이에요”→첫 사이드 보상 1회. 보류·중단 “다음에도 도울 수 있어요”→PAUSED 및 MAIN_CURSOR 복귀. 재대화 DONE “새 정기 분류 일감도 있어요”→별도 WORK_ID, 칩 0 수입 반복. 어린 마을 주민은 무베팅 규칙 학습판에만 등장.
# 거대 카지노 타워
## 03-T01 거목의 실제 최상층
**조건:** 솔개 소개 또는 F5 자율 방문, 선택형. 로비에는 전망경기 안내 직원과 위쪽으로 이어지는 거대 수직 구조가 보인다. 직원 "나무 줄기 경기장은 긴 판, 꼭대기 솔개 대표와 직접 겨루려면 아래층 정식 기록부터요."
**저층:** 뿌리 안 작은 공개 매치, **중층:** 줄기 층에서 스택을 오래 운영하는 긴 매치, **최상층:** 가지 전망대 위 솔개 특별전. 포커 매치 실제 완료 결과로 다음 층 도전 자격/보상; 패배하면 안전 수입/무료 연습 후 재도전 가능.
솔개 "급하게 올라온 사람은 오래 못 앉아요. 일단 시작하죠." 정상 승 "내가 기다리는 동안 네가 판을 가져갔네"→대형 게임 재화·목각 기념품·선택형 빠른 수레 루트; 정상 패 "시간 들여 다시 올라와요"; 미도전해도 항구 정기 교통과 공식 예선 참가권 변함 없음.
### 03-T01 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 타워 L 무료 로비→A 뿌리 공개 경기→B 줄기 긴 정식 경기→C 솔개 정상, 각 층 별도 MATCH_ID. 직원 “구경은 무료, 실제 참가하려면 이 층 기록을 확인해 주세요.” 조건 미충족·칩 0→“무료 연습과 식당 견과 일감은 열려 있어요. 항구행도 막지 않습니다”, WIN→“다음 층 신청 가능”, LOSS→“같은 층 다시/로비/여행 계속 중 선택”, WITHDRAW→“이미 통과한 층은 유지.” 정상 실제 WIN에만 T03_CLEAR 및 첫 보상, 솔개 “지난번엔 당신 판이었군요”; 패/미참여 “다음 기회에도 위에 있어요.” 출구는 저장된 MAIN_CURSOR 또는 F6 교통, 타워 재진입으로 메인 첫 장면 재연 금지.
# 재방문
## 03-R01 위아래 마을의 후일담
**조건:** 항구 이상 방문 뒤 숲 재입장. 03-S01 성공이면 다리 개통/미완이면 주민 공사 진척과 우회계단 유지. 미루 "이제 수레도 저녁엔 손님 많아요." 견과 보관고와 식당은 대회 논란과 무관하게 영업, 안전 수익 반복 가능.
### 03-R01 선택 후 대사·재대화·복귀 (v4.2)
**보완:** REGION04_VISITED 후 F0/F3 복귀. 다리 S01 DONE→미루 “표 맞춰 준 날부터 통행이 좋아졌어요”, 미완·거절→“우리가 교대하며 고쳤어요. 우회계단은 여전히 있어요.” 견과 S02 DONE→식당 “지난번 자루 정리 고마웠어요. 오늘도 일할래요?”, 미참여→“정기 분류 일감은 여전히 열려 있어요.” 선택 “마을 둘러볼래/도윤 소식/여행 계속”→F3/03-R02/현재 MAIN_CURSOR. 재방문으로 S 최초 보상 중복 지급 금지.
## 03-R02 경기 이후의 솔개·도윤
**조건:** F4 또는 F5 재방문. 주인공이 도윤과 직접 매치 승이면 관련 방송에 "전에 내가 졌던 사람"이라는 도윤 짧은 응답, 패면 "다음엔 다르게 와", 미참여면 "아직 직접 못 붙었네"로 정확히 구분. 솔개 정상 승 "지난번 네가 내 정상 가져갔지" / 패 "다시 할래?" / 미도전 "경기장 위에 아직 자리 있어요." 도윤의 항구 NPC 경기 결과를 숲에서 주인공 직접전 결과로 둔갑시키지 않음.
### 03-R02 선택 후 대사·재대화·복귀 (v4.2)
**보완:** 도윤 직접전 WIN/LOSS/WITHDRAW/NOT_ENTERED를 별도 조회: “숲에서는 네가/내가 가져갔죠/그때 중간에 멈췄지/아직 직접 붙지 않았죠.” 도윤이 항구에서 이안을 이긴 NPC 사건은 별도 결과로만 말한다. 솔개 정상 WIN→“내 정상에서는 지난번 네가 이겼지”, LOSS→“같은 층 재도전해요”, NOT_ENTERED→“로비 관전부터 해도 돼요.” “다시 붙을래”→별도 새로운 실제 매치/선택형 T01, “지역 이동”→현재 MAIN_CURSOR/교통. DONE 메인과 첫 보상 재지급 금지.
# 실패 경로·다음
수직 경로 실패→안전 체크포인트, 다리 미수리→우회계단, 시범전 관전 스킵→결과판으로 도윤 소개, 도윤 직접전 패/미참여→항구 경기 정상, 솔개 최상층 패·칩 0→견과 분류 또는 무료 연습·정기 항구 교통. 지역 04에 도착하기 전 이안-도윤 NPC 경기 승패를 미리 확정 대사로 알리지 않는다.
