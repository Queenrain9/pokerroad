# 장면 범위·장소 지도
골목 아파트 앞 P0→슈퍼 평상 P1→문방구/분식집 P2→오락실 앞 작은 공개 예선 P3→큰 새봄 카지노 타워 입구 P4(높은 건물과 로비)→편의점/강변행 정기 버스 정류장 P5. P2 소액 일과 P4 정상 도전은 자유 순서. 처음 타워의 상층은 길지 않게 **층 안내와 공개 관전만** 가능, 최상층 실제 도전은 이후도 계속 열려 있다.
# 메인 장면 원고
**v4.2 공통:** MAIN_CURSOR=첫 미완 메인 장면 ID; DONE 장면 재진입은 완료 대사만, 최초 보상 중복 지급 금지. S/T/R을 선택하면 MAIN_CURSOR를 저장하고 종료·거절·패배 후 복귀한다. 직접 참가·관전·미참여·중도포기는 서로 다른 기록이며 한 핸드 승리와 매치 우승을 혼동하지 않는다. 칩 0에서도 무료 연습/관전·비도박 수입·기본 지역 교통 유지.
## 01-M01 골목 게시판 — 처음 움직이는 주인공
**조건/인물:** 새 게임/지역 첫 도착, 아파트 문 밖에 주인공, 슈퍼 손님. **연출·행동:** 이름/외형 선택→걸어서 골목 입구/게시판 조사. 카메라는 주민과 놀이터를 지나 멀리 네온 건물 상단을 잠깐 보여 준다. 게시물 "오늘 오락실 앞 동네 공개 예선. 처음이면 슈퍼 앞 무료 판부터." 퀘스트 UI의 선택지는 ‘무료 연습·예선 접수·동네 둘러보기’ 세 가지.
슈퍼 손님 "오늘도 저 할머니가 판 다 끝냈어." 주인공 ① "어디서요?" → "슈퍼 평상. 옆에 빈 의자 있어." ② "오락실은 어디예요?" → "저기 게임기 소리 나는 골목." ③ "그 건물은 뭐예요?" → "동네 타워지. 가까이 가면 보일걸."
**완료/다음:** 게시판 확인 또는 슈퍼 직원 안내 수령→01-M02와 예선 안내 활성. 게시판 무시하고 돌아다녀도 표지가 P1에서 다시 보인다. 아무 경기 기록은 만들지 않음.
### 01-M01 실제 진행·대사·조건 보완 (v4.2)
**보완 — 첫 진입/재대화:** NEW_GAME에서 P0 게시판 조사 또는 P1 주민에게 길을 물으면 START_ACK=TRUE, MAIN_CURSOR=01-M02. “동네부터 볼게요”→손님 “그럼 슈퍼 골목에서 다시 봐요.” 재대화·지도 미완→“게시판은 저쪽, 무료 판은 슈퍼 앞이야.” 완료 후→“오락실 가려면 게임기 소리 따라가.” 탐험하다 P3에 먼저 닿아도 접수 가능하며 복례 연습 승리 기록을 만들지 않는다. 선택형 S02/T01 방문·종료 시 현재 MAIN_CURSOR로 복귀.
## 01-M02 복례와 첫 무료 판
**조건/인물:** P1 진입, 복례·슈퍼 손님. 복례는 평상에서 동네 손님과 실제 작은 카드판을 접고 컵을 한쪽에 밀어 둔다.
손님 "어떻게 자꾸 내 패를 알아요?" 복례 "네가 말 다 했잖아."
주인공 ① "저도 앉아도 돼요?" → "저기 빈자리. 돈 안 걸어도 돼." ② "구경할게요." → "내 컵만 안 쏟으면 돼." ③ "처음이라…" → "그럼 버튼부터 봐."
**조작:** 무료 규칙 튜토리얼의 가능한 행동과 스택/팟을 실제 조작. 숙련자 도움 건너뛰기는 관전/규칙 도움 확인으로 처리, **복례를 이겼다는 기록 생성 금지**. 이겼다면 "어? 이번엔 네가 가져갔네. 난 슈퍼 문 닫기 전에 장 좀 봐야겠다." 졌다면 "한 판 졌다고 끝은 아니지. 연습판은 무료야." 관전만 했다면 "오락실 가서 직접 해 봐. 여기서 구경만 해도 재미는 있고."
**완료·다음:** TUTORIAL_SEEN 또는 TUTORIAL_SKIPPED 기록, P3 예선 접수 안내 열림. 패배·돈 0·도움 건너뛰기가 지역 이동을 막지 않음.
### 01-M02 실제 진행·대사·조건 보완 (v4.2)
**보완 — 선택 직후부터 출구까지:** 최초 P1 진입은 M01 안내 또는 자율 발견. “앉아 볼래요”→복례 “돈 안 걸어도 괜찮아. 버튼부터 보자”→실제 무료 튜토리얼 매치, 결과 WIN/LOSS/WITHDRAW만 튜토리얼 ID에 기록. “구경할게요”→손님 “저쪽에서 카드가 보여”→VIEWED, 개인 승패 없음. “나중에”→복례 “접수 먼저 하고 와”→SKIPPED; M03 접수와 버스 개방은 어느 선택에도 유지. 승 “연습에선 네 판이지”, 패 “버튼 다시 볼래?”, 중단 “그럼 여기까지 하자.” 재대화 미완 “오늘도 무료야. 직접 칠래, 구경할래?”, 완료 “오락실 접수 끝나기 전에 가.” 완료 시 MAIN_CURSOR=01-M03, P3 경로 표시. 평상 연습판과 정상전은 독립.
## 01-M03 오락실에서 이안을 만나다
**조건/인물:** P3 입구, 오락실 접수원 해찬(가칭)·이안. 이안은 참가자 공개 기록표를 보지만 주인공 손패를 훔쳐보지 않음.
이안 "그렇게 봐도 내 카드는 안 보여." 주인공 ① "기록 보고 있었는데?" → "그건 내가 올린 거니까 보든지." ② "너도 처음이야?" → "세 번째. 그래도 떨려." ③ "후원 테스트 붙었다며?" → "붙었어. 오늘 판도 본다더라."
해찬 "예선은 이쪽. 구경은 저쪽. 둘 다 동네 사람 환영이에요."
**조작:** 무료 첫 참가권으로 P3 지역 오픈 경기 접수, 또는 공개석 관전. ‘첫 참가권’은 현금 과금/고액 칩 요구 아님. 참가 시 실제 독립 MATCH_ID 부여, 이안이 같은 대진에 나오면 그 직접 결과로만 이안의 이후 대사를 판정. 기본 원고는 이안 별도 조의 NPC 공식 경기. **완료·다음:** 참가→01-M04-P, 관전→01-M04-V. 마감 시간 놓치면 다음 짧은 회차 또는 관전 경로가 있어 주요 이야기를 못 보게 하지 않음.
### 01-M03 실제 진행·대사·조건 보완 (v4.2)
**보완 — 등록·거절·마감:** M02 완료/스킵 또는 P3 선발견 시 해찬 “첫 참가권 쓸래요, 구경할래요?” 직접 신청→“참가자 이름을 확인할게요”→REGISTRATION=ENTERED, 별도 PLAYER_EVENT_ID. 관전→“표는 여기요”→REGISTRATION=VIEW. 조건 부족·마감→“다음 짧은 회차 신청이나 오늘 관전 중 골라요”; 기다림/관전 중 하나를 택하면 바로 M04. 이안과 같은 조가 아닐 때 “우리 조 다르네. 네 판 끝나고 얘기하자.” 재대화 접수 전→“신청/관전 어느 쪽이에요?”, 접수 후→“선수석/관람석으로 가세요”; M04 완료 뒤→“강변 소식은 이안한테 들어 봐.” MAIN_CURSOR=01-M04로 진행하며 S01을 무시해도 참가 명단은 직원이 정상 관리.
## 01-M04 첫 공식 기록
**장소/인물:** 오락실 앞 천막 아래 공개 토너먼트, 접수원·주민, 이안은 별도 조. **플레이 참가:** 실제 카드와 AI로 경기를 진행해 매치 최종 결과·예선 실적을 저장. 단일 팟 승리만으로 전체 예선 우승/본선 자격을 부여하지 않는다. 경기 종료 후 승/입상 "이름 남았어요. 다음 공개전도 신청할 수 있어요." 탈락 "오늘 기록은 여기까지. 연습판과 다음 회차는 열려 있어요." **관전:** "어떤 경기인지 봤죠? 다음엔 원하면 직접 신청해요." 참가 전적 없음.
**이안 독립 결과:** 이안은 이전 실적과 **주인공과 별도 NPC 테이블**의 성적으로 스카우트 연락 수령. 주인공이 같은 테이블에서 이안을 직접 이겼다면 그 경기의 실제 결과를 남기고, 스카우트 기준을 이안의 이전 성적으로만 설명. 주인공에게 거짓으로 "이안도 오늘 무패"라고 소개하지 않는다.
**완료:** R01_MATCH_END/VIEWED, RESULT 별도 저장; 다음 01-M05 자동 행사 종료 후 열림. 포커 패배해도 정기 버스와 카지노 로비 입장 가능.
### 01-M04 실제 진행·대사·조건 보완 (v4.2)
**보완 — 분기와 경기 결과 반환:** ENTERED→실제 지역 공개전 매치 시작, WIN/LOSS/WITHDRAW/COMPLETE_RANK를 경기 엔진 종료 결과로만 받는다. 경기 진행 중 나감→해찬 “진행 중이던 경기는 기록대로 정산하거나 새 회차를 기다려요”; 미완을 승리 처리하지 않고 공식 종료 또는 대체 관전으로 M05. VIEW→진행자 “오늘은 관람이군요”→결과판 확인, PLAYER_EVENT_RESULT=NOT_ENTERED. 승/입상 “이번 성적표 여기 있어요”, 탈락 “다음 회차는 저기서 접수해요”, 중단 “끝낸 회차만 공식 기록이 됩니다.” 관전 스킵해도 결과판으로 이안 별도 NPC 스카우트 소식 확인. 재대화 완료→“본인 기록 확인했죠? 이안은 뒷골목에 있어요.” MAIN_CURSOR=01-M05; 이안 직접전 여부는 실제 매치 ID만 참조.
## 01-M05 이안은 먼저 떠난다
**장소:** P3 뒷골목. **조건:** 01-M04 종료 또는 결과 게시판 확인. 이안이 여행 가방과 새 강변 초청전 포스터를 들고 나온다.
이안 "강변 야간 초청전에 자리가 났어. 나 먼저 간다."
주인공 ① "나도 그 경기 나갈래." → "현장 오픈 신청은 알아봐. 너도 직접 등록해야 돼." ② "구경하러 갈게." → "배 쪽 관람석에서 보자." ③ "우리 먼저 붙기로 했잖아." → "못 만났으면 거기서 한 판 예약하자."
**직접전 이미 있음:** 이안 "그때 네가 이겼지" / "그때 내가 이겼지"는 01-M04의 직접 **매치 결과가 있을 때만** 추가. **완료:** IAN_RIVER_SCHEDULE=TRUE; 태도 R01_TRAVEL_MOTIVE 저장. 다음 01-M06, 자유 동네 탐험 가능. 이안의 계약서 장문 설명 없음.
### 01-M05 실제 진행·대사·조건 보완 (v4.2)
**보완 — 이안 직접전 조건:** 이안과 실제 같은 매치에서 최종 승/패 기록이 있으면 “그날 네가/내가 이겼지.” 미참여·다른 조→“우리 아직 직접 붙지 않았네.” 중도포기→“그날은 끝까지 못 쳤잖아.” “나도 출전할래”→“공개 신청 조건은 현장에서 확인해. 내 초청 자리는 네 자리가 아니야.” “구경만”→“승선장 관람석에서 보자.” “연습판 약속”→“배 도착하고 따로 앉자.” 재대화 완료→“난 출발할게. 타워는 복례 할머니에게 물어봐.” 모든 선택에 IAN_RIVER_SCHEDULE=TRUE, MAIN_CURSOR=01-M06; 직접전 없는 플레이어에게 과거 승리 언급 금지.
## 01-M06 큰 타워의 정상에 있는 사람
**장소:** P4 초입, 높은 타워 건물 전체가 보이고 광장 전광판에 "최상층 대표 복례" 광고. **조건:** 01-M05 또는 P4 자율 첫 방문. 복례가 장바구니를 들고 타워 출입 직원과 친숙하게 인사.
주인공 ① "아까 슈퍼 앞 할머니예요?" → 직원 "네, 최상층 대표세요." ② "지금 붙을 수 있어요?" → "로비 관전부터 보시고 정식 도전을 예약해 주세요." ③ "평상에선 제가 이겼는데요?" (연습판 실제 매치 승 기록 있을 때만) → 복례 "평상은 평상이고, 위에서는 오래 앉아야 해."
복례 "예약 시간 확인하고 올라와. 나 장 보고 들어갈게."
**행동:** 카지노 로비 무료 관광·첫 층 관전·층별 경기 보상 확인. 01-T01을 선택해서 계속하면 메인 출발을 나중에 해도 되고, P5 강변행 정기편으로 갈 수도 있음. **완료:** TOWER_INTRO_SEEN. 복례 과거 회상/비밀 조종자 설정 금지.
