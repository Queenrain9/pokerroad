# 읽기·상태 계약
2026-09-25 보완. 기존 M 6·S 2·T 1·R 2 장면 ID를 유지한다. 각 장면의 아래쪽 선택·재대화·연결이 원문의 생략된 분기를 구체화한다. 원문의 요약과 충돌 시 같은 장면의 보완된 조건을 적용한다. 경기 결과·퀘스트 완료·보상 지급은 서로 다른 기록이다. MAIN_CURSOR는 메인 첫 미완 장면이며 S/T/R 진입 때 보존, 출구에서 복귀한다. 완료한 M은 다시 실행하지 않고 최신 사건 단계의 재대화만 재생한다. 먼저 탐색한 장소는 발견 상태만 기록하며 선행 사건 완료 전 후반 대사를 미리 재생하지 않는다.
Q는 공식 경기 기록 판정 YES/NO/PENDING이며 이 문서가 임의로 수여하지 않는다. 칩 0일 때에도 필수 대화·관전·지역 기본 교통·엔딩은 무료다. 07-W01은 새 메인 장면이 아닌 반복 일감 내부 식별자다. 선택 활동의 수치/AI는 별도 구현 의존성이고 아래 경로 검수는 문서 범위다.

**플레이:** 카드 참여(승리와 무관)/공연 관전/등불 전망 발견/공연자 물품 전달 4개 중 **서로 다른 2개** 활동을 하면 야시장 작은 스탬프 2개를 획득. 이 활동은 지역 특산 간식·공개 무대 좌석 혜택일 뿐 N7 교통권/공식 본선 자격 아님. 활동 거절/실패 후에는 다온의 무료 노점 산책이 기본 필수 이벤트로 인정돼 07-M02로 이어짐. **완료:** R07_MARKET_EXPERIENCED→07-M02. 경기 참여 여부와 승패 별도 기록; 고액 판 패배해도 시장 일감/무료 기본 정기선 제공.
### 선택 뒤의 대화·재대화와 진행
다온: “카드판은 골목 안쪽, 공연은 등불 밑이에요. 천천히 보고 와요.”
- “경기부터 갈게요.” → 다온: “빈손이면 무료 판에 앉아요. 돈 거는 판은 따로 표시돼 있어요.” N2 직원: “연습할까요, 구경할까요?” 직접 승리: “이번 연습판은 가져가셨네요.” 패배: “다음 판도 무료예요.” 관전: “여기서 패가 공개될 때 같이 보세요.” 시작 전 취소: “자리 안 잡아도 괜찮아요. 무대는 저쪽이에요.” 경기 중 떠나기: “진행 중인 판을 그만둘까요?” 확인 시 중도포기로만 저장.
- “공연 볼래요.” → 소명: “막 다음 곡 들어가요. 길 가운데만 비워 주세요.” 관람 후 다온: “저 팀은 새벽에도 한 번 더 해요.”
- “먹거리랑 전망대부터요.” → 다온: “구경은 공짜예요. 계단 위에서 강까지 보여요.” 칩 0이면 구매를 요구하지 않고 전망 난간 조사로 지역 경험을 기록.
- “지금은 아무것도 안 할래요.” → 다온: “그럼 저랑 입구만 돌아요. 큰 무대 가는 길 알려 드릴게요.” 무료 안내 수락 또는 안내 표지 확인으로 07-M01 완료. 안내도 닫으면 같은 위치에 안내 표지가 유지되며 강제 경기 없음.
재대화 미완: 다온 “무대 찾고 있어요? 이 등불 따라가면 돼요.” 완료: “봉희 씨 순서가 곧이에요. N3 무대에서 봐요.”
**진입·종료:** 06-M05 완료 후 최초 입장. 스탬프 2개는 선택 보너스일 뿐, 활동 하나의 관람/체험 또는 무료 안내 확인으로 R07_MARKET_EXPERIENCED를 기록하고 07-M02 활성. 보너스는 서로 다른 활동당 한 번, 교환도 한 번. 사이드 07-S01/07-S02나 07-T01로 빠지면 MAIN_CURSOR=07-M02를 보존한다.
## 07-M02 봉희가 경기와 공연을 함께 진행한다
**조건/장소:** N3 공개 무대, 대표 봉희·관람객. 공연 끝나자 별도 주민 공개 포커 이벤트가 시작된다. 봉희 "이제 카드를 치죠. 공연은 다음 순서에 준비해 주세요." 관전 NPC 이벤트 1\~2차례 공개 행동만 보여 주고 긴 동영상 강제 재생 금지. 조건을 충족한 플레이어는 **별도 공개 직접 매치** 참여하거나 구경 선택, 자기 경기 결과는 실제 엔진 매치 결과만 보존.
주인공 "봉희님은 타워 맨 위에도 있나요?" → 봉희 "공연 없는 시간엔 올라와요. 아래층부터 올라와 보면 만나죠." 성공 공개 경기 "오늘 손님 한 명 더 유명해졌네요"; 패배 "다음 공연 때 다른 상대 찾아봐요"; 관전 "구경도 무료예요."
**완료:** BONGHUI_PUBLIC_STYLE_SEEN, N6 카지노 로비 소개→07-M03. 봉희 정상 승리를 본선 명단 공개의 선행조건으로 만들지 않음.
### 직접전·관전·미참여의 후속 발화
봉희: “무대 앞 판에 앉을래요? 구경할 자리는 저쪽에도 있어요.”
- “직접 칠게요.” → 진행자: “이 판 참가 조건부터 확인할게요. 타워 대표전이나 전국 예선과는 다른 경기예요.” 자격·참가 비용을 충족하면 별도 매치. 미충족/칩 0이면 “지금은 정식 참가가 어렵네요. 무료 연습판과 관람석은 열려 있어요.” → 무료 연습/관전/미참여 선택. 무료 연습 결과를 봉희 정식전 승리로 바꾸지 않는다.
- “보고 갈게요.” → 봉희: “좋아요. 이번엔 내가 얼마나 오래 기다리나 봐요.” 공개 시연 확인 후 진행자: “중앙 전광판에서 다음 대회 안내가 나와요.”
- “경기는 안 볼래요.” → 봉희: “그러면 길만 비켜 주세요. 이쪽은 곧 경기 시작해요.” 로비/대표 소개판의 공개 시연 요약을 확인하고 STYLE_SEEN 기록; 승패와 관전 전적은 만들지 않는다.
실제 완주 승/패는 기존 경기 후 대사, 중도포기는 봉희 “끝까지 못 앉아 있었네요. 다음 일정에 다시 신청해요.”로 구별. 플레이어 경기가 끝나지 않았거나 취소 확인을 하지 않으면 이 매치만 보류; “지금 그만두고 전광판으로”를 항상 제공한다.
재대화 완료: 봉희 “정상 예약은 타워 로비에서 받아요. 지금 발표는 전광판 쪽이에요.” 미완: 진행자 “앉을지, 볼지, 안내만 읽을지 골라 주세요.”
**연결:** 07-M01 완료→07-M02. 직접전 승·패·중도포기 / 관전 / 소개만 확인 모두 07-M03. 선택형 07-T01 종료 시 07-M03으로 복귀, 타워 승리 불필요.

**인물 행동:** 나래는 자기 이름의 이의 신청을 직접 등록, 도윤은 다음 07-M04에서 **조건부** 공개 재예선 제안을 할 수 있다고만 말함. 주인공 대사 선택만으로 기존 예약 취소·나래 복구·원탁 승인 발생하지 않음. **완료:** R07_TEMP_LIST_SEEN; 임시 상태 유지→07-M04.
### 질문 뒤의 행동과 재대화

## 07-M04 도윤의 조건, 이안의 계산
**조건/장소:** N5 공용 주민 경기장과 N1 옆 후원팀 접촉 카페, 운영자·나래·도윤·이안. 주민 경기장 운영자 "여긴 원래 누구나 작은 공개전을 칠 수 있어요. 다만 전국 결승 출전권으로 인정하려면 원탁과 운영위원회가 정식 경기라고 승인해야 합니다." 
도윤 "그 공개 선발전을 정식으로 인정하면, 내가 거기서 치죠. 그때 현재 예약을 내려놓을게요." 나래 "나는 내 예선 결과를 바꿀 생각 없어요. 내 신청은 내가 할게요." 이 제안은 **아직 확정도 실행도 안 됨**.
이안은 자신의 원탁 지원 계약의 대리 변경 조항이 적용될 수 있다는 공지를 받고 있다. "여기까지 연습한 시간이 있어서 그런 조건은 못 받아들여. 그렇다고 받은 지원까지 없던 건 아니지." 주인공 ① "그럼 팀 나와"→"정산부터 따져 봐야지." ② "다음에 직접 붙자"→"일정 끝나면 한 판은 꼭." ③ "당장 명단 고쳐"→"내 이름부터 내가 확인할게." 이안의 최종 정산·대리 조항 변경은 시티 08-M05 시점까지 보류.
**행동:** 주인공은 주민의 실제 무료/소액 공개 미니 매치에 직접 참가하거나 관전해 '새 경기를 연다'는 제안이 단순 말장난이 아님을 본다. 승패는 주민 이벤트 결과로만 기록하며 공식 본선 자격을 이 미니판 한 번으로 수여하지 않는다. **완료:** DOYUN_CONDITIONAL_WILDCARD_INTENT, IAN_NEGOTIATION_OPEN=TRUE→07-M05.
### 공개 판과 이안 재대화
운영자: “주민 판은 지금도 열려 있어요. 전국 선발전 승인은 다른 문제예요.”
- “주민 판에 앉을게요.” → “무료 연습부터 할 수 있어요. 이 판으로 본선표를 드리지는 않아요.” 무료/소액 선택 후 실제 승리: “오늘 주민 판 기록은 여기 남길게요.” 패배: “이 판은 끝났어요. 무료 연습은 계속할 수 있어요.” 중도포기: “여기서 중단한 걸로 남길게요.”
- “구경할게요.” → “줄 바깥 관람석으로 와요. 누구든 볼 수 있어요.”

# 재방문
## 07-R01 계속 열리는 장터

## 07-R02 임시 대진표의 갱신
**조건:** N4 전광판 재확인. 시티 08-M04 이전엔 "임시 대리 예약·나래 이의 진행/도윤 조건부 제안", 08-M04 완료·08-M05 전에는 "성적자 복구·와일드카드 승인, 경기 대기", 08-M05 이후에만 "도윤 별도 와일드카드 결과". 진입 날짜만으로 자동 복구하지 않고 스토리 플래그로 판정. 봉희 정상 승/패/미도전별 재도전 안내; 이안의 재협상 완료는 시티에서만 사실로 기록.
### 사건 시점별 전광판과 확인 대사
**표시 우선순위:** 현재 진행 플래그를 읽고 아래 한 구간만 표시한다. 08-M04 직후에는 도윤의 와일드카드 결과를 아직 보여 주지 않는다.
- 08-M04 미완: 수리 “아직 임시 명단이에요. 나래의 이의 신청과 도윤의 조건부 제안은 처리 중입니다.” 08-M03 완료라면 추가 “약속한 중계 회차는 멈췄고 수정안은 아직 발표 전이에요.”
- 08-M04 완료·08-M05 미완: 수리 “성적자 자리는 복구됐고 도윤은 대리 예약을 반납했어요. 와일드카드 경기는 아직 결과가 안 나왔어요.”
- 08-M05 완료: 수리 “도윤은 별도 공개 선발전 성적으로 들어갔어요. 이안의 계약 변경도 끝났고요.” 주인공 승패는 별도 실제 기록만 표시.
봉희 관련 질문 “타워는 그대로 열려요?” → 직원: 격파 이력 있음 “지난번 기념품을 받으셨죠. 새 매치 예약은 가능합니다.” 패배만 있음 “통과해 둔 층부터 재도전해요.” 미도전 “로비부터 구경해 보세요.” → 07-T01. 칩 0은 무료 로비/07-W01.
“그럼 내 일정으로 갈게요.” → 수리 “시티 본인 등록 창구에서 확인하세요.” → 07-M06 반복 출구→현재 08-M 미완 장면. “여기 더 있을게요.” → “새 발표는 이 화면에 남겨 둘게요.” → 07-R01/자유 활동.
**조건:** 07-M03을 본 뒤 N4 재조사. 재대화는 같은 현재 상태 문구를 짧게 반복하고 M03\~M05를 재연하지 않는다. STORY_END 후에도 이 상태는 과거로 돌아가지 않는다.
**v4.2 시티 연계 재검수:** 07-M05의 OFFICIAL_INTENT/SHOWMATCH_INTENT/VIEW_INTENT와 CHECK_PENDING을 08-M01이 모두 받아 Q=YES/NO/PENDING 상태별로 접수·무료 관전 또는 적격 별도 공개전을 안내하도록 수정했다. Q=PENDING에서 시티로 먼저 갔더라도 공식 출전권을 가정하거나 명단 발표를 중복 재연하지 않고 08-M06 관전 결과 확인 후 엔딩으로 연결한다. 08-M04 이전에는 나래 복구·도윤 예약 취소 표시 금지. 기존 Work의 장면별 보완 대사는 덮어쓰지 않았다.
# 반례 검수
스탬프 하나도 못 모은 경우: N3 공연 구경/지역 동선 경험만으로 N4 이벤트 가능, 모든 스탬프를 교통 필수조건으로 설정 안 함. 도윤 직접전 미참여/봉희 미격파/노점 사이드 미완/경기 패배/칩 0 모두 08 진입. Q=NO 시티에서 공식 대회 선수로 방송 호명 금지. 임시 명단 공개 직후 도윤이 대리 예약을 내려놓고 나래가 즉시 공식 좌석 복구되는 기존 v3 순서 오류 재발 금지.
