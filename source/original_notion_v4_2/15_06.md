**v4.2 공통:** MAIN_CURSOR=다음 미완 메인 ID. 사이드/타워/재방문 방문은 커서를 저장해 완료·거절·패배 뒤 반환. DONE 메인은 현재 상태 재대화만, 첫 보상 중복 지급 금지. 플레이어와 은솔 NPC 경기는 별도 MATCH_ID, 이안 재협상은 07 이전 REQUESTED 상태만. 칩 0에도 무료 관전·지역 교통·비도박 일감.

## 06-M01 성문 앞의 은솔
**조건/장소·인물:** 05-M05 이후 G0\~G2, 안내원·신참 도전자 은솔. 주인공이 한복 시장에서 누각의 높은 기와지붕과 장인들의 작은 판을 본다.
안내원 "경연 구경은 왼쪽, 공개 출전은 오른쪽. 참가 조건은 저기 공고에 적혔습니다." 은솔 "추천받은 명인은 바로 안으로 가는데, 난 공개 접수부터 해야겠네."
주인공 선택 ① "너도 경기 나가요?" → "그래서 여기까지 왔죠." ② "추천 없으면 못 나가요?" → "공개 경연이 따로 있어요. 직접 해 봐야죠." ③ "궁궐 구경부터" → "연못 돌아오면 여기서 봐요."
**행동/완료:** 공고 확인, 자유 시장 산책, 본인이 조건 맞는 경우 정식 공개 경연 신청 또는 관전표 받기→06-M02. 은솔 추천장을 대신 찾아 주는 강제 퀘스트 없음. 참가 자격 없는 플레이어도 무료 관전 경로 존재.

## 06-M02 같은 테이블의 실제 경기
**조건/장소:** G3 낮 경연, 은솔·추천 명인·공개 진행자. 진행자 "추천받은 명인과 공개 접수 도전자의 경기를 시작합니다."
**NPC 장면:** 은솔과 명인의 별도 NPC 경기에서 정해진 경기 결과는 **이 두 NPC만 참가한 관전 이벤트**로 제공. 1\~2회 의미 있는 공개 액션과 결과판을 보여 주고, 플레이어가 본인 경기처럼 버튼을 눌러 승패 바꾸게 하지 않는다. 은솔 NPC 승일 땐 "오늘만큼은 먼저 들어온 사람과 같은 자리였네", 패일 땐 "다음 경연엔 또 신청할 거예요" 정도로 짧게 반응. 결과는 제작 시 실제 유효 포커 리플레이로 구현해야 함.
**주인공 경기:** 접수된 플레이어는 **다른 조/별도 시간의 정상 포커 매치**에 참가. 최종 경기 승리·패배·중도 포기·관전만 각각 다른 개인 기록. 승리한 플레이어→접수원 "당신 경기 기록은 여기서 확인해요." 패배→"다음 공개전 일정도 있대요." 관전→"다음에는 원하면 접수하세요." 은솔 NPC 결과와 주인공 성적 불일치 오류 금지.
**완료:** PUBLIC_COURT_SEEN, PLAYER_COURT_MATCH_RESULT 별도→06-M03. 고액 판돈/경기 승리가 다음 지역 해금 필수 아님.
### 06-M02 실제 선택 후 대사·조건·복귀 (v4.2)
**보완:** G3 안내원 “직접 참가·은솔 경연 관전·결과 요약 중 골라 주세요.” 플레이어 적격 참가→PLAYER_COURT_MATCH_ID로 실제 독립 포커 매치; 최종 WIN “오늘 경기 성적을 여기서 확인해요”, LOSS “다음 공개전도 접수 가능해요”, WITHDRAW “완료된 라운드만 기록합니다.” 관전/자격 부족/칩 0→“무료 관람석은 열려 있어요”; 요약→“은솔의 별도 NPC 경연 결과는 여기 있어요.” 은솔 NPC 경기 WIN/LOSS는 별도 EVENT_ID, 주인공 버튼/결과와 무관. 은솔 해당 경기 패 “내일도 공개전은 열려 있어요”, 승 “오늘 내 경기 결과는 여기 있네요”, 관전 건너뛴 사람에겐 “게시판에서 결과 봤어요?”라고 묻는다. 경기/요약 확인으로 DONE_06_M02→M03; 미완 재대화 “참가하거나 결과를 확인해 주세요”, 완료 “월인 대표는 누각 쪽입니다.”
## 06-M03 월인의 생활과 누각
**조건/장소:** G3→G5 앞, 지역 카지노 대표 월인·장인. 월인은 공개 경기에서 침착한 베팅과 자신의 수가 틀렸을 때 카드를 정리하는 실제 일상을 보여 주고, 장인과 기와 수리 계획을 확인한다.
월인 "추천받은 분도 공개로 들어온 분도, 내 누각에서는 아래층부터 한 판씩 해 보시죠." 주인공 ① "아까 경연보다 어려워요?" → "올라갈수록 긴 판이죠." ② "구경만 하고 가도 돼요?" → "그럼요. 전망대는 구경만 해도 좋아요." ③ "나중에 다시 올게요" → "밤 연회 끝나도 타워는 열려 있어요."

## 06-M04 이안의 경기 복기와 재협상 시작
**조건/장소:** G3 연못 벤치 또는 G4 밤 연회 옆 작은 연습 테이블, 이안. 이안은 항구에서 도윤에게 진 **별도 NPC 경기**의 방송 리플레이를 열어 놓고 있다.
이안 "그날 난 영상 속 도윤하고만 싸웠더라. 여기서는 내 앞의 사람을 보고 치려고." 주인공 ① "그럼 나랑 연습할래?" → 실제 별도 공정 매치 등록 ② "팀에서 나오면 되잖아" → "훈련비도 이동 지원도 받았는데 그걸 없던 일로 할 수는 없지." ③ "후원팀이 다른 사람 보낸다며?" → "대리 지정 조항은 고쳐 달라고 말할 거야."
**승패:** 이안과 직접 매치 승리 "오늘은 네가 가져갔어" / 패 "이번 판은 내가 가져갈게" / 미참여 "장터에서 다시 보자"; 주인공이 지역 01/02에서 이안과 실제 붙은 기록이 있을 때만 "그때랑 또 다르네" 한 줄 추가. 이안은 본인의 판단으로 담당자에게 대리 지정 조항 수정 요청 **신청만** 한다. "다음 대회 지원은 보장 못 한다"는 담당자 답변이 도착하지만 최종 동의는 장터 명단 발표 이후에 함.
**완료:** IAN_RENEGOTIATION_REQUESTED=TRUE, 이안 직접전 RESULT는 별도→06-M05. 주인공의 '팀 나와' 대사만으로 지원 계약 자동 종료 금지.

**보완:** 연회 진행자 “은솔과 장인을 찾아볼래요? 틀려도 괜찮아요.” 은솔 말투 선택→“맞았어요, 오늘은 연회 손님이군요”·기념 간식, 다른 사람 선택→“힌트: 낮 공개 경연에서 말하던 그 목소리예요”→재시도/그만두기. 거절 “연회 구경은 자유예요”, 중단 “내일 밤에도 열려요.” DONE은 최초 보상 1회, 다시 오면 다른 연회 인사만. M05 장터행·전국 예선 자격을 가면 퍼즐에 연결하지 않음. 모든 출구 MAIN_CURSOR.
# 거대 누각 카지노
## 06-T01 월인 최상층 특별전
G5 기와누각 로비→연못 전망 아래층 공개전→대형 격자창 중층 정식 경기→최상층 월인 특별 포커. 직원 "정상에 오르는 분은 아래층부터 정식 경기 기록이 있어야 합니다. 관광은 로비까지 무료예요." 정상 입장 전 월인 "구경 끝났으면 카드를 봅시다."
주인공 각 층 매치의 실제 최종 성적에 따라 상층 **선택형** 도전 가능, 실패하면 G1 안전 수입/무료 연습 후 재도전. 정상 승 "오늘은 당신의 판이네요"→큰 게임 내 상금·누각 기념품·궁중 주민의 호감 대사, 패 "다음 경연 때 다시 오시게"→재도전. 정상 승리가 궁궐행 전철/장터행 행렬, 전국 결승 자격을 열어 주지 않음.
### 06-T01 실제 선택 후 대사·조건·복귀 (v4.2)
**보완:** 누각 L 무료 로비→A 연못 공개 매치→B 격자창 중층 정식 매치→C 월인 최상층 별도 실제 경기, 각 층 MATCH_ID. 직원 “정식 신청/무료 관전/경연장 돌아가기 중 고르세요.” 부적격·칩 0→“지금 경기 신청은 어렵지만 무료 전망과 시장 일감, 장터 정기 이동은 열려 있어요.” A/B 실제 매치 WIN에만 다음 층 자격, LOSS→“같은 층 다시 도전하세요”, WITHDRAW→“기존 층 통과 기록은 보존합니다.” C 실제 WIN에만 T06_CLEAR·첫 보상, 패 “다음 경연에도 타워는 열려 있어요”, 미도전 “로비 구경부터.” 출구에서 MAIN_CURSOR 또는 G6 교통, 본편 공식 출전권은 생성하지 않음.
# 재방문
## 06-R01 은솔의 다음 경기
**조건:** 장터 이후 G2/G3 재입장, 은솔은 다른 공개전에 다시 등록한다. 06-M02 은솔 NPC 관전 결과를 알고 있다면 승/패에 맞춰 "그날은 내가 이겼지만 오늘은 다시 시작"/"그날 졌어도 공개전은 계속 열리잖아", 스킵 관전이면 "저번 공개전 결과판 봤어요?"로 시작. 주인공 개인 경연 승/패/관전 기록은 별도 안내원 대사만 바꿈. 일상 공개 경연 계속 운영.
### 06-R01 실제 선택 후 대사·조건·복귀 (v4.2)
**보완:** REGION07_VISITED 이후 G3 재방문. 은솔의 NPC 공개전 승/패는 별도 경기 ID로 “그날은 내가 이겼지만 다시 도전해요/그날은 졌지만 오늘도 공개전이 있죠.” 관전 스킵→“그날 결과판 봤어요?” 플레이어 직접 경연 WIN/LOSS/WITHDRAW/VIEW는 안내원 자신의 기록 대사만 달라짐. “다른 공개전 참여”→새 실제 경기 ID, “연회 구경”→G4, “장터 돌아가기”→현재 MAIN_CURSOR/정기편. 이전 보상을 재지급·경기 우승을 강제하지 않음.
## 06-R02 누각·연회의 시간
월인 타워 정상 승 "지난번 정상의 승자는 당신이었지" / 패 "한 판 더 하시겠소?" / 미도전 "로비 전망대는 아직 무료요." S02 성공 시 진행자 "가면 누군지 이제 알겠죠", 실패 "오늘은 또 누가 숨었을까요". 낮 장인과 밤 연회의 방문 동선 지속, 안전 일감·정기 이동 항상 열림.
### 06-R02 실제 선택 후 대사·조건·복귀 (v4.2)
**보완:** G5/G4 복귀 때 월인 정상 WIN “지난번 정상은 당신이 가져갔지”, LOSS “그 경기 다시 치르겠소?”, NOT_ENTERED “로비 전망은 무료요.” 연회 퍼즐 DONE→진행자 “그날 목소리는 기억나죠?”, 오답·미참여→“오늘도 가면 손님은 많아요.” “타워 재도전”→T01 새 MATCH_ID, “무료 생활 일”→G1 별도 WORK_ID, “다른 지역”→현재 MAIN_CURSOR. STORY_END 뒤에도 같은 동네 일상 유지, 메인 M01\~M05의 첫 등장 장면 재연 금지.
